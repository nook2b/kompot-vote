# Kompot Vote

Голосование группы комедийной импровизации «Компот» за форматы шоу.

- Раунд 1: каждый выбирает 3 формата, топ-3 выходят в финал.
- Раунд 2: каждый выбирает главный формат (слот 2) и, по желанию, что играть в слоте 1 — или «сыграть главный дважды».
- Итог: программа вечера на таймлайне.

Подробности — в [PLAN.md](PLAN.md). Как писать описания форматов — в [FORMATS_BRIEF.md](FORMATS_BRIEF.md).

## Как устроено

| Что | Где |
|---|---|
| Страница | `index.html`, `app.js`, `style.css`, `assets/` — GitHub Pages |
| Адрес бэкенда | `config.js` |
| Бэкенд | `apps-script/Code.js` — Google Apps Script, привязанный к таблице |
| Данные | Google Таблица «Kompot Vote — голоса» в папке «Kompot Vote» на Google Диске |
| Форматы для демо | `data/formats.json` |

Пока в `config.js` пустой `apiUrl`, страница работает в **демо-режиме**: голоса хранятся только в браузере, на экране входа есть тестовые коды.

## Запуск (один раз, около 10 минут)

### 1. Подключить скрипт к таблице

1. Открой таблицу «Kompot Vote — голоса» → **Расширения → Apps Script**.
2. Удали всё в файле `Code.gs` и вставь содержимое [`apps-script/Code.js`](apps-script/Code.js). Нажми «Сохранить».
3. **Начать развертывание → Новое развертывание** → тип **Веб-приложение**:
   - «Выполнять как»: **Я**;
   - «У кого есть доступ»: **Все**.
4. Разреши доступ к таблице (Google предупредит, что приложение не проверено: «Дополнительно → Перейти»).
5. Скопируй URL веб-приложения (заканчивается на `/exec`) и вставь его в `config.js` в `apiUrl`.

После правки `Code.js` нужно обновить развертывание: **Начать развертывание → Управление развертываниями → ✏️ → Версия: новая**. Иначе работает старый код.

### 2. Опубликовать страницу

1. GitHub → репозиторий → **Settings → General → Danger Zone → Change visibility → Public**.
2. **Settings → Pages → Build and deployment → Deploy from a branch**, ветка с кодом, папка `/ (root)`.
3. Через минуту страница откроется по адресу `https://nook2b.github.io/kompot-vote/`.

### 3. Прогон

1. Открой личную ссылку админа из листа «Участники», потом ссылку участника и гостевую.
2. Пройди оба раунда, проверь итог.
3. В админке нажми «Стереть все голоса и начать заново».
4. Разошли личные ссылки (колонка «Личная ссылка»).

## Коды

- Коды и роли — на листе «Участники». Меню «Kompot Vote» появляется в таблице после того, как скрипт сохранён и таблица перезагружена. Роли: `участник`, `гость` (только смотрит), `админ`; можно `участник, админ`.
- Новый человек: впиши имя и роль, затем меню **Kompot Vote → Выдать коды и ссылки**.
- Ссылку переслали не тому: выдели строку и **Kompot Vote → Перевыпустить код выделенного участника**.

## Локально

```bash
python3 -m http.server 8000
```

Затем открой `http://localhost:8000/` — это демо-режим.
