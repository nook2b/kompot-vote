# Kompot Vote — план

Внутренняя страница, на которой команда голосует, какие импро-форматы играть на шоу (≈ 1,5 часа).

Структура шоу: **Конферанс → Слот 1 → Слот 2**. Слот 2 — главный формат вечера. В слоте 1 может быть другой формат (например, короткие скетчи), тот же формат второй раз или ничего (тогда главный формат идёт весь вечер).

---

## 1. Хостинг и данные

- **Страница** — GitHub Pages: `https://nook2b.github.io/kompot-vote/`. Бесплатный GitHub Pages работает только для **публичного** репозитория — владелец разрешил сделать его публичным.
- **Голоса** — Google Таблица «Kompot Vote — голоса» в папке «Kompot Vote» на Google Диске владельца. Страница общается с таблицей через веб-приложение Google Apps Script (скрипт привязан к таблице, код лежит в `apps-script/Code.js`).
- В репозитории только код и описания форматов. **Коды участников в репозиторий не попадают** — они есть только в таблице, а таблицу видит только владелец.
- Подсказка: страница опрашивает таблицу раз в 7 секунд, поэтому результаты появляются у других с небольшой задержкой. Для команды из десяти человек квот Apps Script хватает с запасом.

## 2. Вход по кодам

- У каждого свой цифровой код (5 цифр), привязанный к имени. У Инны простой код `1111`.
- Каждому рассылается **личная ссылка** `…/kompot-vote/?code=12345`. Вход в один тап, телефон запоминает участника. Если ссылка потеряется, код можно ввести вручную.
- Роли (колонка «Роль» на листе «Участники»):
  - **участник** — голосует и видит результаты после своего голоса;
  - **гость** — только смотрит результаты, не голосует и не считается в «проголосовали N из M». Один общий гостевой код — для Игоря (Bensdance) и ещё пары людей;
  - **админ** — управляет голосованием на странице «Управление». Можно совместить: «участник, админ» — так у Ивана Бурлакова.
- Участников, роли и коды админ правит прямо на странице «Управление»: добавить, переименовать, сменить роль, выдать новый код, удалить. Голоса привязаны к имени и при новом коде сохраняются.

## 3. Механика голосования

### Раунд 1 — три финалиста

- Карточки всех форматов. Каждый участник выбирает **ровно 3 разных** формата.
- После голоса сразу видно общий результат и «проголосовали 7 из 9».
- Голос можно поменять, пока раунд открыт (у каждого всё равно один голос).
- Три формата с наибольшим числом голосов становятся финалистами.

### Раунд 2 — главный формат и пожелание на слот 1

Голосуют те, кто голосовал в первом раунде. Каждый делает два выбора:

1. **Главный формат** (слот 2) — один из трёх финалистов. Обязательно.
2. **Слот 1** — по желанию, один из вариантов:
   - без пожелания;
   - **«сыграть главный формат дважды»** (оба слота — один формат, на разные подсказки);
   - любой другой формат: сначала показаны остальные финалисты, остальные форматы — под раскрывашкой.

Под выбором — таймлайн вечера, который показывает, влезает ли программа в 90 минут.

### Итог

- **Слот 2** = финалист с наибольшим числом голосов за главный формат.
- **Слот 1** = вариант с наибольшим числом пожеланий. «Дважды» засчитывается как голос за тот же формат в слоте 1. Если победил главный формат — играем его дважды. Если пожеланий нет совсем — главный формат на весь вечер.
- Админ видит предложенный итог и может его поправить перед объявлением.

### Ничьи

- За третье место в раунде 1: админ отмечает, кто проходит. Можно пропустить всех поделивших, но финалистов не больше 5.
- За главный формат или слот 1: админ выбирает вручную. На экране админки ничья подсвечивается.

## 4. Таймлайн шоу

- Горизонтальная полоса на длину шоу (по умолчанию 90 минут): **Конферанс → Слот 1 → Слот 2**.
- Длительности форматов — диапазоны («30–40 мин»), поэтому итог тоже диапазон: «Итого 65–85 из 90 мин».
- Цвет итога: зелёный — влезает с запасом; жёлтый — может не влезть по верхней границе; красный — не влезает даже по нижней.
- Длительность конферанса (по умолчанию 10 минут) и шоу меняются в админке.

## 5. Экраны

Не одна длинная страница, а короткие экраны, которые открываются по очереди. Светлая тема, на компьютере — шире и в две колонки.

1. **Вход** по коду или личной ссылке.
2. **Раунд 1:**
   1. приветствие: что нужно сделать и сколько уже проголосовали;
   2. форматы по одному на экран: описание, структура, что от зала, реквизит, опыт. Кнопки «←», «Выбрать», «→» и точки для быстрого перехода;
   3. «Твой выбор»: три слота, можно поменять, кнопка «Отправить голос»;
   4. «Голос принят» и результаты.
3. **Раунд 2:**
   1. приветствие с финалистами;
   2. шаг 1 — главный формат;
   3. шаг 2 — первый слот (по желанию);
   4. шаг 3 — «Так выглядит вечер»: таймлайн и отправка;
   5. «Голос принят» и результаты.
4. **Итог.** Программа шоу на таймлайне, под ним «Как голосовали».
5. **Управление** (отдельная вкладка у админа):
   - открыть первый раунд, открыть второй с выбранными финалистами (по умолчанию топ-3), объявить итог с выбранными слотами (по умолчанию победители), вернуться на раунд назад — в любой момент, голоса сохраняются;
   - кто проголосовал в каждом раунде; стереть голос одного человека, стереть раунд 1, раунд 2 или всё сразу;
   - участники и коды: добавить, переименовать, роль, новый код, скопировать личную ссылку, удалить;
   - включить или скрыть форматы;
   - длительность конферанса и шоу.

Форматы правятся прямо на листе «Форматы»: можно поменять текст, а колонкой «Активен» скрыть формат.

Экран для проектора не нужен.

## 6. Технически

- **Фронтенд:** статичные `index.html`, `app.js`, `style.css` без сборки. Мобильная вёрстка, тёмная тема в цветах логотипа.
- **Бэкенд:** `apps-script/Code.js` — веб-приложение Apps Script. Вся логика голосования в одной функции `kvHandle`, отдельно от чтения и записи таблицы.
- **Правила проверяются на сервере:** в раунде 1 ровно 3 разных формата; в раунде 2 главный формат только из финалистов, и голосуют только те, кто голосовал в первом; гость не голосует; управлять раундами может только админ. Записи идут под блокировкой, чтобы одновременные голоса не затирали друг друга.
- **Демо-режим:** пока в `config.js` не указан адрес веб-приложения (или если открыть страницу с `?demo`), страница работает на той же логике, но хранит голоса в браузере. На экране входа — тестовые коды, в админке — кнопка «накидать голоса за остальных».
